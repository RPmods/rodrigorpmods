# Recursos pendientes para Nora

Nora ya está registrada en el sistema Draft como personaje de **The Scissors**.

Coloca sus recursos con estos nombres exactos:

```text
strinova/img/characters/thumbs/Nora.png
strinova/img/characters/full/Nora.png
strinova/img/characters/Nora.png        # fallback opcional
strinova/audio/voices/pick/Nora.mp3     # voz opcional
strinova/audio/voices/ban/Nora.mp3      # voz opcional
```

Mientras las imágenes no existan, el sistema mantendrá reservado el personaje y usará su fallback visual habitual para recursos faltantes.

El rol de combate de Nora está configurado como `Vanguardia` (`Vanguard` en inglés). Su facción es `The Scissors` y puede participar como atacante.
